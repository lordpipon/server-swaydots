## Some default controls (SUPER is the WIN key)
SUPER + SHIFT + E - exit sway/logout
SUPER + Q - exit app
SUPER + W - open default browser (firefox esr)
SUPER + E - open file manager (dolphin)
SUPER + ENTER - open terminal
SUPER + SPACE - open application launcher
SUPER + SHIFT + SPACE - make floating window
SUPER + LMB - drag to move windows
SUPER + RMB - resize windows
